# docs/adr/

Decisoes arquiteturais individuais (ADR), para quando um bloco de `docs/DECISIONS.md`
crescer demais ou exigir discussao longa.

Regra: comeca sempre em `DECISIONS.md`. Vira ADR so quando o bloco passar de ~1 pagina
ou quando houver alternativas com trade-off que mereca seu proprio documento.

Nome do arquivo: `NNN-titulo-em-kebab-case.md`, com o mesmo numero do `DEC-NNN` de
origem, e um link nos dois sentidos.

Estrutura: Contexto / Decisao / Alternativas consideradas / Consequencias / Status.

Hoje: vazio. Todas as 13 decisoes cabem em `docs/DECISIONS.md`.
